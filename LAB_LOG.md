# Lab Log

One line per session. Sixty seconds to fill. This is your re-entry point: when you come back
after a break, the last row tells you exactly where you were, what's snapshotted, and anything
that was weird. Never reconstruct state from memory — read it here.

**Columns**

- **Date** — when.
- **Part** — which chapter you worked.
- **Gate** — did you pass the chapter's verification gate? `Y` / `N` / `partial`.
- **Snapshot** — the name of the snapshot you took at the end (so you know what to restore to).
- **Notes** — anything that surprised you, broke, or that you want to remember. Future-you is grateful.
